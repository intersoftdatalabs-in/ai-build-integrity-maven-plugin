# Security Policy

## Reporting a Vulnerability

We take the security of the **AI Build Integrity Maven Plugin** seriously. If you have discovered a security vulnerability in this project, we appreciate your help in disclosing it to us in a responsible manner.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Please report security issues directly to the maintainers:

* **Email**: security@intersoftdatalabs.com (or via the [Intersoft Data Labs GitHub organization](https://github.com/intersoftdatalabs-in))
* **Security Advisories**: You can also use the GitHub "Report a vulnerability" feature if enabled on the repository.

Please provide a clear description of the vulnerability, including:

* A summary of the issue.
* Steps to reproduce.
* The potential impact of the vulnerability.
* Any suggested mitigations.

We will acknowledge your report as soon as possible and work with you to resolve it.

## Supported Versions

Only the latest stable version of the plugin is supported for security updates.

| Version |     Supported      |
|---------|--------------------|
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Responsible Disclosure

We ask that you follow responsible disclosure principles:

* Give us a reasonable amount of time to fix the issue before sharing details publicly.
* Do not exploit the vulnerability beyond what is necessary for a proof of concept.
* Do not harm other users or disrupt the project.

Thank you for helping us keep the AI supply chain secure!
